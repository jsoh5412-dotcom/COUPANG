## 목표
테크트리 1단계(기획)를 맡을 기획 팀장을 만든다. 규칙은 `planning/CLAUDE.md`에 이미 있다.

## 작업
1. `git pull origin main` 후 `planning/CLAUDE.md`, 바뀐 `ROADMAP.md`를 읽는다.
2. 기획 팀장 워크트리 `~/coupang-agent-planning`을 만들고 `.env`를 PM 폴더 것으로 심볼릭 링크한다 (상페 팀장과 같은 방식, 키 값은 읽지 않는다).
3. 드라이브 동기화 폴더에서 `planning/CLAUDE.md`의 참고 파일들이 열리는지 확인한다(파일 존재·접근만, 내용 수정 금지).
4. `.env`에 `DOMEGGOOK_API_KEY`가 비어 있으면 사용자에게 도매꾹 OpenAPI 발급 절차를 확인해 알려 준다.
5. 사용자가 세션을 여는 방법을 보고서에 적는다: Code 탭 → 새 세션 → 이 컴퓨터 → 폴더 `~/coupang-agent-planning/planning` → `/rename 쿠팡-기획-팀장` → Remote Control 켜기.
6. 기획 팀장의 첫 지시 문안을 보고서에 함께 적는다: "`planning/CLAUDE.md`와 루트 문서 읽고, `최종_2609`의 합격 품목 6개를 최신 기준(조건 시트)으로 다시 검증해서 품목 리포트를 올려."

## 완료 기준
- 워크트리와 `.env` 링크가 있고, 보고서 `hq/reports/261027_PM_기획팀장신설.md`에 세션 여는 방법과 첫 지시 문안이 있다.
