# 지시서: 상페 저장소 이사 (PDP-Converter_forCOUPANG → COUPANG/pdp)

- 발행: 쿠팡-본부-전략팀장 · 2026-10-26
- 대상: 쿠팡-본부-운영팀장-PM
- 상태: 완료 (hq/reports/261026_PM_상페저장소이사.md)  <!-- 대기 → 진행 → 완료(보고서 링크) | 보류(사유) -->
- 관련 결정: DECISIONS.md #2, #23

## 목표
지금의 쿠팡-상페-팀장은 클라우드 세션이라 맥북의 크롬 쿠팡 프로필·폴더·세션 간 메시지를 쓸 수 없다. 상페 저장소 내용을 COUPANG 모노레포로 옮겨, 맥북 로컬 상페 팀장이 `~/coupang-agent/pdp`에서 바로 일할 수 있게 한다.

## 사전 조건 (사용자가 먼저 처리)
- 사용자가 클라우드 상페 팀장에게 "모든 작업 커밋·푸시, 브랜치 목록 보고"를 시킨 뒤 이 지시서를 시작한다.
- 시작 전 원격 `PDP-Converter_forCOUPANG`의 브랜치 목록을 확인하고, `main` 외 브랜치에 병합 안 된 작업이 있으면 사용자에게 보고하고 어떻게 할지 묻는다.

## 작업
1. **이력 보존 이사.** `PDP-Converter_forCOUPANG`의 `main`을 커밋 이력째로 가져온다 (예: 별도 클론에서 모든 파일을 `pdp-import/` 경로로 옮긴 뒤 `--allow-unrelated-histories`로 병합, 또는 `git subtree add`). 방법은 PM이 고르되 이력이 남아야 한다.
2. **폴더 배치.** 가져온 파일을 `pdp/` 아래 기존 구조(`config/`, `scripts/`, `templates/`, `projects/`)에 맞게 정리한다. 수집기·리뷰 분석·번역처럼 다른 팀도 쓸 코드는 `shared/`로 옮긴다. 판단이 애매하면 `pdp/`에 두고 보고서에 적는다.
3. **규칙 파일 병합.** 기존 `pdp/CLAUDE.md`(본부 작성)와 상페 저장소의 `CLAUDE.md`(팀장 작성)를 하나의 `pdp/CLAUDE.md`로 합친다.
   - 두 파일이 다르게 말하는 부분은 **고치기 전에 목록으로 보고**한다 (승인 관문: 규칙 변경).
   - 루트 `CLAUDE.md`와 `DECISIONS.md`가 우선한다. 특히 결정 16(타깃 기본값 없음), 20(크롬 쿠팡 프로필), 21(로그인 의존 최소화).
4. **경로 수정과 동작 확인.** 스크립트 안의 경로(`templates/pdp/` 등)를 새 위치에 맞게 고치고, 상페 저장소에서 했던 것과 같은 샘플 렌더(가로 780px 분할 출력)를 한 번 돌려 정상 동작을 확인한다. 유료 이미지 생성 API는 호출하지 않는다.
5. **비밀 정보 점검.** 가져온 이력과 파일에 API 키·`.env`가 커밋된 적이 있는지 확인한다. 있으면 즉시 보고한다(해당 키는 폐기 대상).
6. **문서 갱신.** `ROADMAP.md`·`ARCHITECTURE.md`·`README.md`의 "별도 저장소에서 작업 중, 추후 이사" 표기를 갱신한다.
