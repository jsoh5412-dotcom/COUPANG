## 배경
세트 1 상페 v1 17개는 사용자가 보고 "너무 허접하다"고 했다. 원인: 사용 장면 사진 0장(AI 이미지 미사용, CSS 그래픽 대체), 누끼 + 글자 + 둥근 카드 반복, 품질 기준 없음, 지나친 속도. 결정 42로 시범 1개를 제대로 만들어 제작 방식을 확정한 뒤 나머지에 적용한다.

## 작업 (상페 팀장)
1. `git fetch` 후 최신 main에서 `pdp/pilot-heel-file` 브랜치. 바뀐 `pdp/CLAUDE.md` "품질 기준"을 먼저 읽는다.
2. 드라이브 `상세페이지/테스트세트1/1_발각질제거기_1_손잡이+양면/`의 v1 파일을 같은 폴더 `_v1/`로 옮긴다(삭제 금지).
3. 레퍼런스(바렌 157030810, 더마풋 9472616029) 상세를 다시 본다. 이번에는 구조가 아니라 **장면별 비주얼**(어떤 사진을, 어떤 크기·구도로, 글자와 어떻게 겹쳤는지)을 섹션마다 `analysis/ref_visuals.md`에 적는다.
4. **레파토리 먼저:** 레퍼런스·리뷰를 바탕으로 이상적인 섹션 구조를 먼저 짠다. 가진 사진은 아직 고려하지 않는다.
5. **컷 리스트:** 섹션마다 필요한 컷을 `shotlist.md`로 뽑는다(장면, 제품 등장 여부, 구도, 용도). 실사 장면 최소 6컷.
   - 그다음 컷마다 출처를 찾는다: 공급처(화이트 61798554 기준) 사진 → 무료 스톡 → AI 장면 + 누끼 합성 → 그래픽 순서 (`pdp/CLAUDE.md` 품질 기준 1).
   - 끝내 못 구한 컷은 메시지는 살리고 표현만 바꾸고, `촬영필요.md`에 남긴다.
5-1. 레퍼런스와 잘 팔리는 쿠팡 상페의 **화려한 그래픽 장치**(확대 원, 화살표, 비교 그래픽, 큰 숫자·배지·리본, 그라데이션·입체 타이틀, 형광펜 강조, 아이콘 인포그래픽, 효과, 오버레이 라벨 등)를 섹션마다 적극 쓴다 (`pdp/CLAUDE.md` 품질 기준 5). 장치는 가져오되 도안·문장은 새로 만든다.
6. AI 이미지 생성(제품 없는 발·손·욕실·배경 등)과 누끼 합성. **예산 1만 원까지 묻지 않고 쓴다.** 실제 쓴 금액을 기록한다.
7. 렌더 → 레퍼런스와 나란히 비교 이미지 → 약한 섹션 고치기 → 다시 비교. 최소 2번 반복.
8. 썸네일도 같은 방식으로 다시 만들고 레퍼런스 썸네일과 비교한다.
9. 결과물은 드라이브 같은 폴더(새 파일), 비교 이미지도 함께. 카드 상페 칸 갱신.
10. 보고: 걸린 시간, 이미지 비용, 비교 이미지 경로, 레퍼런스 대비 아직 약한 점(솔직하게).

- 제품 자체를 AI로 만들지 않는다. 확인 안 된 주장(녹·304·반영구 등)은 쓰지 않는다.
