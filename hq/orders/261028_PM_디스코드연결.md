# 지시서: 디스코드 연결 (PM 봇 시범 → 팀장 확대)

- 발행: 쿠팡-본부-전략팀장 · 2026-10-28
- 대상: 쿠팡-본부-운영팀장-PM
- 상태: 대기  <!-- 대기 → 진행 → 완료(보고서 링크) | 보류(사유) -->
- 관련 결정: DECISIONS.md #40

## 목표
사용자가 폰(갤럭시 DeX + 스마트 안경)에서 디스코드로 보고를 받고 빠르게 지시할 수 있게 한다. 주 도구는 계속 Remote Control이다. 이번 작업은 테스트 세트 1 상페 제작을 방해하지 않게 한다(상페 팀장 세션은 시범이 끝나고 제작이 한숨 돌릴 때 옮긴다).

## 사용자가 할 일 (PM이 보고서에 단계별 안내를 쓴다)
1. 디스코드에서 비공개 서버 `쿠팡 본부`를 만든다. 채널: `#보고`, `#pm`, `#기획`, `#상페`.
2. 디스코드 개발자 포털에서 봇 3개를 만든다: `쿠팡-PM`, `쿠팡-기획`, `쿠팡-상페`.
   - 각 봇: Message Content Intent 켜기, Public Bot 끄기, 권한(View Channels, Send Messages, Send Messages in Threads, Read Message History, Attach Files, Add Reactions)으로 서버에 초대.
3. 토큰은 채팅·스크린샷으로 보내지 않는다. 넣는 방법은 PM이 정해 안내한다 (예: 원격 화면으로 맥북에서 직접 붙여넣기).
4. 디스코드 개발자 모드를 켜고 사용자 ID와 채널 ID를 PM에게 알려 준다 (ID는 비밀이 아니다).

## PM이 할 일
1. Bun이 없으면 설치하고, 공식 플러그인 `discord@claude-plugins-official`을 설치한다.
2. 봇마다 상태 폴더를 따로 둔다 (`DISCORD_STATE_DIR`, 예: `~/.claude/channels/discord-pm`, `-planning`, `-pdp`). 토큰은 그 폴더의 `.env`에만 둔다. 저장소에 넣지 않는다.
3. **시범: PM 세션부터.** 터미널에서 `~/coupang-agent`로 `claude --channels plugin:discord@claude-plugins-official`을 켜고 세션 이름 `쿠팡-본부-운영팀장-PM`, Remote Control도 켠다. 상시 실행 방법(터미널 유지, 맥 재시동 후 복구)을 정한다.
4. 접근 설정: DM은 `allowlist`(사용자 ID만), 채널은 `#pm`과 `#보고`만 `--allow <사용자 ID>`로 연다. 다른 봇 메시지에는 반응하지 않는다.
5. 시범 확인 항목 (보고서에 결과):
   - 디스코드 `#pm`에서 보낸 지시가 세션에 들어오고 답이 오는지
   - 같은 세션이 Remote Control(claude.ai·앱)에서도 계속 보이고 쓸 수 있는지
   - 권한 요청이 생기면 어디로 오는지 (디스코드로 오면 사용자 본인만 승인 가능한지)
   - `#보고`에 완료 알림을 올릴 수 있는지
6. 시범이 되면 기획 팀장, 상페 팀장 순으로 같은 방식으로 옮긴다. 각 팀장은 자기 팀 채널 + `#보고`만 연다. 옮기는 동안 진행 중인 작업이 끊기지 않게, 팀장이 한 작업 단위를 마친 뒤 옮긴다.
7. 보고 규칙을 팀장들에게 알린다: 상품 하나 끝, 막힘, 사용자 결정 필요 시 `#보고`에 한두 줄. 상페 완성본은 썸네일 등 미리보기 이미지를 첨부해도 된다(원본은 드라이브).
8. 시범에서 채널과 Remote Control이 함께 안 되거나 권한 요청이 처리 안 되면, 옮기지 말고 멈추고 보고한다.

## 완료 기준
- PM·기획·상페 봇이 각자 채널에서 사용자 지시를 받고, `#보고`에 알림을 올리며, 세 세션 모두 Remote Control로도 보인다. 보고서 `hq/reports/261028_PM_디스코드연결.md`.

## 승인 관문
- 봇 생성·토큰 입력은 사용자. 그 외는 결정 40 범위.
