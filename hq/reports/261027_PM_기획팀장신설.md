## 도매꾹 OpenAPI 키 — 비어 있음, 사용자 발급 필요
`.env`의 `DOMEGGOOK_API_KEY`가 비어 있다(값 유무만 확인). 도매꾹 OpenAPI 안내 사이트 기준 절차:

1. 도매꾹에 로그인한 상태로 **API 발급/관리** 페이지에 접속한다: https://mobile.domeggook.com/APIs/gate
2. **Open API 키 발급**을 고른다. Open API 키는 발급 즉시 쓸 수 있다.
   - Private API(주문·상품 연동용)는 관리자 승인이 필요하다(영업일 2~3일). 기획 팀의 상품·가격 조회에는 필요 없을 것으로 보이나, 안내 글에 "조회만 하는 경우"의 유형이 명시돼 있지 않다.
3. 발급된 키를 맥북 `~/coupang-agent/.env`의 `DOMEGGOOK_API_KEY=` 뒤에 직접 넣는다 (채팅·스크린샷으로 보내지 않는다, `SETUP.md` 3단계). 기획 팀장 워크트리는 링크로 같은 파일을 쓴다.

- 안내 문서: [API 신청 가이드](https://openapi.domeggook.com/ko/articles/API-%EC%8B%A0%EC%B2%AD-%EA%B0%80%EC%9D%B4%EB%93%9C-787a96cd), [Open API / Private API 발급](https://openapi.domeggook.com/ko/articles/Open-API--Private-API-%EB%B0%9C%EA%B8%89-75c11d02)
- 안내 문서에 없는 것: 입력 항목, 호출 한도, 도매매 상품 조회에 같은 키를 쓰는 범위. 궁금하면 techsupport@ggook.com 문의 (공급처 연락이 아니라 API 기술 문의).
- 키가 들어오기 전까지 기획 팀장은 도매꾹·도매매를 공개 페이지로 확인한다 (`planning/CLAUDE.md`).
