- **경로 점검.** 가져온 코드는 모두 저장소 루트 기준 `pdp/…`·`shared/…` 경로를 쓰고, `pdp/templates/base.html`은 `pdp/projects/<상품>/work/pdp.html` 위치에서 `../../../templates/components.css`로 CSS를 찾는다. 새 위치와 맞아서 고칠 경로는 없었다.
- **문서 갱신.** `README.md`·`ROADMAP.md`·`ARCHITECTURE.md`의 "별도 저장소에서 작업 중, 추후 이사"를 "이사 PR 검토 중, 병합 후 맥북 로컬 세션으로 재신설"로 바꿨다. 지시서 상태는 `진행`으로 바꿨다.

## 비밀 정보 점검
- 상페 저장소 전체 이력(3커밋)에 등장한 파일 경로 중 비밀 정보 의심 파일은 `.env.example` 하나이고, 값은 모두 비어 있다.
- 전체 diff에서 OpenAI(`sk-`), AWS, Google(`AIza`), GitHub 토큰, 슬랙 토큰, 개인키 패턴, 값이 들어간 `*_API_KEY=`·`SECRET`·`TOKEN`·`PASSWORD` 할당을 검색했고 0건이다.
- `.env`는 이력에 한 번도 커밋되지 않았다. **폐기할 키 없음.**

## 샘플 렌더
- **아직 못 돌렸다.** 맥북에 Node.js가 없다(`node`, `npm` 없음). Playwright용 크롬은 `~/Library/Caches/ms-playwright`에 이미 있다.
- Node 설치(Homebrew, 맥북 전역)는 사용자 승인 후 진행한다. 설치되면 `pdp/`에서 `npm ci` 후 `base.html`로 780px 분할 렌더를 돌리고 이 칸을 채운다. 유료 이미지 생성 API는 호출하지 않는다.

## 막힌 것 · 바꾼 것
- 지시서는 상페 저장소 `main`을 가져오라고 했으나 `main`이 없어, 사용자 확인 후 `claude/fervent-pascal-c7d7sl`을 가져왔다.
- 지시서 예시의 `pdp-import/` 경유 대신 원래 경로로 바로 병합했다. 이력은 같게 남고 `--follow` 없이도 이어진다.
- `pdp/CLAUDE.md`는 아직 하나로 합치지 않고 모노레포 판을 유지했다. 충돌이 위 A 1곳뿐이고, 그 1곳은 결정 16에 맞는 쪽이 이미 모노레포 판이다. 상페 쪽에만 있는 규칙은 없다.
