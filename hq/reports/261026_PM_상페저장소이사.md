- **이력 보존 병합.** `pdp/migration` 브랜치에서 `git merge --allow-unrelated-histories`로 병합했다(커밋 3개 `acd3c67`·`a62940a`·`26e01b6` 보존). 상페 저장소가 이미 `pdp/`·`shared/` 경로를 쓰고 있어서 `pdp-import/`를 거치지 않고 원래 경로 그대로 들였다. 덕분에 `git log -- <파일>`이 별도 옵션 없이 이어진다.
- **겹치는 파일 처리.**
  - 루트 `CLAUDE.md`·`README.md`·`.gitignore`·`.env.example`: 상페 쪽은 본부가 예전에 넣어 둔 사본(타깃 50~60대, 건강 제품 주력 등 결정 16 이전 내용)이었다. 모노레포 판을 유지했다. 상페 쪽에만 있는 내용은 없었다.
  - `pdp/CLAUDE.md`: 아래 "규칙 충돌" 참고. 모노레포 판을 유지했다.
  - `shared/README.md`: 상페 쪽이 실제 코드에 맞는 설명이라 반영했다(`collectors/` 리뷰 원문 수집, `reviews/` 지침 위치, `images/` 행 추가).
  - 내용이 생긴 폴더의 `.gitkeep`은 지웠다.
- **경로 점검.** 가져온 코드는 모두 저장소 루트 기준 `pdp/…`·`shared/…` 경로를 쓰고, `pdp/templates/base.html`은 `pdp/projects/<상품>/work/pdp.html` 위치에서 `../../../templates/components.css`로 CSS를 찾는다. 새 위치와 맞아서 고칠 경로는 없었다.
- **문서 갱신.** `README.md`·`ROADMAP.md`·`ARCHITECTURE.md`의 "별도 저장소에서 작업 중, 추후 이사"를 "이사 PR 검토 중, 병합 후 맥북 로컬 세션으로 재신설"로 바꿨다. 지시서 상태는 `진행`으로 바꿨다.
