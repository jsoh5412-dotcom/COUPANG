# shared/ — 여러 봇이 같이 쓰는 도구

| 폴더 | 용도 | 쓰는 곳 |
|---|---|---|
| `collectors/` | 쿠팡·1688·도매꾹 상세 이미지, 쿠팡 리뷰 원문 수집 (로컬 브라우저 기반 고정 스크립트) | 상세페이지, 상품 등록 |
| `reviews/` | 쿠팡 리뷰 분류 (USP, 불만, 사용 맥락). 원문 수집은 `collectors/`. 지침: `review_usp.md` | 상세페이지, 상품명, 광고 소재 |
| `images/` | 누끼(`remove_bg.py`, rembg), AI 실사 이미지 생성·편집(`gen_image.mjs`, OpenAI) | 상세페이지, 광고 소재 |
| `translate/` | 중국어 상세 이미지 분할·판독·번역 | 상세페이지, 상품 등록 |
| `brand/` | 브랜드 색상·폰트 토큰 | 상세페이지, 광고 소재 |
| `notify/` | 디스코드 웹후크 보고(시작·완료·막힘·병합·요약, 이미지 첨부). 결정 40 1단계 | 모든 팀장, PM |

새 도구를 여기 넣을 때는 이 표에 한 줄 추가한다.
