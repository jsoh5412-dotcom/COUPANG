# 사용자 카피 취향 (가장 우선하는 기준)

**사용자에게 예시를 따로 요청하지 않는다.** 재료(참고집·고객 말·팩트)는 봇이 직접 모은다. 이 파일은 사용자가 시범 카피·완성본을 보고 한 판정("좋다/구리다"와 이유)을 전략팀장·PM이 받아 적어 채운다. 사용자가 스스로 예시를 주면 그때 추가한다.

## 지금까지의 판정
- 2026-11-01: 세트 1 v1과 시범 v2를 보고 "카피랑 디자인 둘 다 여전히 구려. 카피는 정말 중요하다." → 규칙만 지킨 밋밋한 설명문은 탈락.
- 2026-11-03: 시범 v3를 보고 "V1·V2보다 훨씬 나아졌지만 아직 만족은 아니다. 뭔가 부족한데 뭔지 모르겠다." → PM이 레퍼런스와 비교해 올린 진단 세 가지에 "다 좋다"고 동의했다.
  - 왜 이 제품이어야 하는지가 약하다. 큰 숫자만으로는 설득이 안 된다.
  - 한 브랜드처럼 보이지 않고 분위기가 무겁다. 색을 통일하고 쓰고 싶어지는 장면을 늘린다.
  - 제품이 진짜처럼 보이지 않는다. 떠 보이는 합성과 흐린 썸네일을 고친다.
- 2026-11-03: 시범 v5를 보고 "지금 v5가 딱 좋아." → 파랑 기준색 톤, v4 카피와 흐름, AI 제품 컷으로 자연스러워진 사진을 기준으로 삼는다. (상페 팀장 전달: v4를 보고 "디자인 톤, 카피, 흐름 다 좋아.")
- 2026-11-03: 수면안대_6 v2(playbook 이전 검증)를 "통과". 재채점 4점 미만 카피 12개와 첫 화면 "나는 깜깜"이 남아 있다는 PM 보고를 본 뒤의 판정이다. 상페 팀장 전달: "비슷함, 15개 진행".
- 2026-11-03: 세트 1 15개 v2를 보고 "카피도 좀 이상하고, 제품 사진도 다 조금씩 이상한 것 같아." → 통과 아님. PM 확인 결과:
  - 제목 263개 중 109개가 다른 상품과 공통이고, 한 페이지에 같은 제목이 반복됐다. 상품마다 따로 쓴 카피가 아니면 어색하게 읽힌다.
  - 설명을 그대로 읽는 제목, 약점을 먼저 말하는 제목은 약하다.
  - AI 컷의 손·발가락 어색함, 컷마다 다른 제품 색, 흐리거나 잘린 사진은 눈에 띈다.
