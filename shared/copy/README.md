# shared/copy — 카피 참고 자료 (여러 팀이 같이 씀: 상페·등록·광고)

- `swipe.md`: 후킹·헤드라인 패턴 참고집. 쿠팡 판매 상위 상페(카테고리 무관)와 사용자가 준 검증된 광고 카피에서 뽑는다. 문장을 그대로 베끼지 않고 **패턴(틀)과 왜 먹히는지**로 정리한다. 출처(상품 번호·배지 구간)를 적는다.
- `safe_phrases.md`: 표시·광고 규정에 걸리는 표현과 힘을 유지하는 대체 표현 사전.
- `user_taste.md`: 사용자가 좋다고 한 카피와 구리다고 한 카피, 그 이유. 가장 우선하는 기준이다.
