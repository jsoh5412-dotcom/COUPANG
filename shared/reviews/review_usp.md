# 03. 리뷰 분석 → USP·핵심가치 지도

경쟁 판매자 리뷰는 "고객이 이 제품을 **왜 사고, 무엇에 만족하고, 무엇이 불안했는지**"의 원천이다.

## 절차
1. 리뷰를 문장 단위로 태깅한다: [구매 계기] [기대] [만족] [불만] [불안 해소] [사용 상황] [선물·대상]
2. 키워드를 묶고 빈도를 센다. 저평점 리뷰는 따로 집계한다.
3. 다음으로 변환한다.
   - 만족 빈도 상위 → **USP 후보**
   - 만족의 이면 → **핵심가치(CV)**: 기능이 아니라 고객 삶의 변화 (예: "흡입력 좋음" → "청소 시간이 절반")
   - 불만 상위 → 내 상세의 **선제 방어** 섹션, 또는 차별점으로 쓸 수 있는지 판정
   - 구매 전 불안 → **불안 제거** 섹션 소재
   - 고객이 실제로 쓴 표현 → 카피에 쓸 **고객 언어 사전** (원문 인용이 아니라 어휘 차용)

## 산출물 `work/03_usp_map.md`
1. 리뷰 표본 요약: 총 개수, 별점 분포
2. **USP TOP 3**: 근거 키워드·빈도와 팩트시트로 확인되는지 여부
3. **핵심가치(CV) 1문장**: 이 제품을 사면 고객의 무엇이 달라지는가
4. **구매편익 리스트**: 기능적 / 감성적 / 경제적
5. **불만 → 대응 전략 표**
6. **타깃 페르소나 1~2개**: 사용 상황, 구매 계기
7. **고객 언어 사전**: 20개 내외
