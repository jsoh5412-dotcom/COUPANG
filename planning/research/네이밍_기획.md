# 브랜드명·제품명 네이밍 기획 (작업 중)

- 작성: 쿠팡-기획-팀장 · 시작 2026-11-17 · 결정 48("테스트는 간단히, 본품 때 제대로")
- 대상: 마진계산기 E열 "브랜드", F열 "제품명 판매관리용(CV+품목명)"
- 상태: **사용자와 방향 맞추는 중.** 확정된 이름은 아직 없다.

## 1. 사용자 요구 (2026-11-17)

- 브랜드는 전부 하나로 통일하지 않는다. **카테고리로 묶을 수 있는 것끼리 묶어 한 브랜드**로 간다.
  - **묶음 확정(2026-11-17 사용자):** ① 생활·웰빙 라이프스타일 = 발각질제거기, 뒤꿈치패드, 수면안대 (s1-01~s1-10) ② 운동 = 필라테스양말, 슬개골보호대 (s1-11~s1-13). 수면안대는 생활·웰빙으로.
  - 그래서 브랜드 이름은 한 품목·한 신체 부위·한 타깃 느낌만 나면 안 된다.
- 제품명은 CV를 있는 그대로 이어 붙인 이름(예: "귀덮개 통짜 수면안대")은 쓰지 않는다.
- **브랜드명과 제품명 모두 상표 등록이 가능한 이름**이어야 한다.
- 품목, CV, 효용, 만족, 추상적·감정적·감각적·물리적 요소를 고루 고려한다.
- 상위 경쟁업체 네이밍 사례를 참고한다.

## 2. 상표 등록 기준 (국내 상표법 기준 통상 판단)

**거절되는 이름**
- 성질 표시(기술적 표장): 품질·효능·용도·모양·원재료·사용법을 바로 알게 하는 말. 예: 실리콘힐, 말랑패드, 꿀잠안대
- 보통명칭·관용 표장: 품목의 일반 이름(수면안대, 토삭스)이나 업계에서 흔히 쓰는 말
- 간단하고 흔한 표장: 한두 글자, 숫자만, 흔한 성씨·지명
- 품질 오인: 실제와 다른 성질을 떠올리게 하는 이름(실크가 아닌데 "실크")
- 선등록·선출원과 같거나 비슷한 이름: 같거나 비슷한 상품 분류에서 소리·모양·뜻이 비슷하면 거절. 실제 거절 사유 1순위.
- 공서양속 위반, 저명 상표 연상

**등록이 잘 되는 이름**
- 조어(새로 만든 말)가 가장 강하다.
- 암시형(간접적으로 떠올리게만 함)도 된다. 예: 컴포럽 = comfort + up
- 감정·감각을 담되 효능을 직접 말하지 않는 조합

**표시·광고 기준도 함께 본다 (콘텐츠 원칙 1):** 닥터·메디·힐(heal)·케어·치료 같은 의료·효능 암시어는 브랜드에도 넣지 않는다.

## 3. 경쟁사 네이밍 사례 (세트 1 레퍼런스 상품)

| 유형 | 사례 | 메모 |
|---|---|---|
| 조어형 짧은 브랜드 | 바렌, 컴포럽, 자요, 케틀럿, 레노브라, 바시스 | 상표로 강함 |
| 설명형 브랜드·제품명 | 더마풋, 베베풋, 깊은잠, 꿀잠, 풋필터 | 기억은 쉽지만 상표로 약함 |
| 브랜드 + 특징 모델명 | 4D 꿀잠, 노필(no feel), X밴더 | 브랜드 아래 제품 이름을 따로 둠 |

- 상위 업체는 브랜드를 조어로 짓고, 제품명은 특징을 살짝 비튼 말로 짓는 경우가 많다.
- 사용자 마진계산기 4행 예시: 브랜드 "소웨이브", 제품명 "구름깔창"(감각 은유 + 품목명).

## 4. 상표 검색 방법

- 특허청 KIPRIS(kipris.or.kr) 상표 검색, 국내, 이름으로 검색(비슷한 이름까지 함께 나온다). 로그인 없이 앱 내장 브라우저로 조회만.
- 볼 상품 분류(니스 분류, 1차 판단):
  - 발각질제거기 08류(손 공구)·21류(미용 도구) / 뒤꿈치패드 10류·25류 / 수면안대 10류·25류 / 필라테스양말 25류 / 슬개골보호대 28류(운동용)·10류(의료용)
- 판단: ◎ 같은 이름·비슷한 이름이 우리 분류에 없음 / ○ 다른 분류에만 있음 / △ 비슷한 이름이 많거나 설명형으로 볼 여지 / ✕ 우리 분류에 같거나 비슷한 등록·출원 있음
- 한계: 1차 확인일 뿐이다. 실제 등록 가능 여부는 출원 때 변리사·심사로 확정된다. 도형·영문 표기 유사는 따로 봐야 한다.
- 네이버 쇼핑 API로 같은 이름 판매 여부도 보려 했으나 2026-11-17 현재 키 인증 실패(401).

## 6. 제품명 방향 (미확정)

- 1차 제안(브랜드 아래 조어 모델명: 허그문, 페더엘, 크로셀 등)은 사용자 의도와 달랐다.
- 사용자 예시 "구름깔창"을 보면 **감각·감정 은유 + 품목명** 형태일 가능성이 있어 확인 중이다.
