# 04. 카피 원고

설계도(01)의 **구조**에 팩트(02)와 USP(03)의 **내용**을 붓는다.

## 규칙
- 섹션 순서는 설계도를 기본으로 하되, 내 제품의 USP 강도에 따라 조정할 수 있다. 조정 이유를 적는다.
- 헤드라인은 2줄 이내, 한 줄 14자 내외(모바일 기준)로 쓴다. 본문은 섹션당 3줄 이내로 쓴다.
- 모든 주장 옆에 근거 태그를 단다: `{F:팩트시트 항목}` `{R:리뷰 키워드}`. 근거 없는 주장은 쓰지 않는다.
- 고객 언어 사전의 어휘를 우선 쓴다. 판매자 말투보다 사용자 말투로 쓴다.
- 금지어 자가 점검: 최고, 1위, 100%, 완벽, 치료, 예방, 영구, 무조건, 타사 비교 비방

## 산출물 `work/04_copy.md`
섹션마다 아래 형식으로 쓴다.
```
## S03 · 문제 제기  (차용: 레퍼런스 S2 "손실 회피")
[헤드라인] ...
[서브] ...
[본문/포인트] ...
[비주얼] 컷 종류, 구도, 필요한 소스 (sup_04 누끼 / 생성 연출컷)
[근거] {F:...} {R:...}
```
마지막에 **썸네일 문구 3안**과 **상품명 3안**(쿠팡 SEO: 브랜드 + 핵심 키워드 + 속성)을 붙인다.

→ 작성이 끝나면 **사용자 검수를 요청하고 멈춘다.**
