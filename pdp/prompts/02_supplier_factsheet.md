# 02. 공급처 팩트시트 (중국어 번역 포함)

공급처 상세는 **사실의 원천**이다. 카피는 이 문서에 있는 내용만 쓸 수 있다.

## 절차
1. 이미지 속 텍스트를 전부 읽는다. 중국어는 원문과 번역을 함께 적는다.
   - 번역은 직역이 아니라 한국 소비자 용어로 바꾼다 (예: 加厚 → "두께 강화", 304不锈钢 → "스테인리스 304").
2. 단위를 변환한다: 斤 → kg, 寸 → inch·cm, 중국 사이즈 → 한국 사이즈(확인 필요 표시).
3. 과장·불확실 표현을 분리한다 (예: "永不生锈 = 절대 녹슬지 않음"은 근거 없음으로 사용 금지).
4. 이미지마다 재사용 가능 여부를 판정한다.
   - 그대로 사용 / 누끼 따서 사용 / 텍스트 제거 후 사용 / 사용 불가(타 브랜드, 저화질)

- **인증·법적 표시**: KC 등 필요 인증 품목인지 여부 → 필요하면 ⚠️로 사용자에게 알린다
- **기능·특징**: 근거 수준을 함께 적는다 (스펙으로 확인됨 / 공급처 주장 / 근거 없음)
- **번역 원문 표**: 이미지 번호, 중국어 원문, 번역
