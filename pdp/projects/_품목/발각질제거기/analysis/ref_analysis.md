## 3. 가져올 결제 장치 TOP 5
1. **첫 화면 = 제품 + 숫자 신뢰 배지.** 바렌은 첫 스크롤 안에 제품명·대표컷·숫자 배지·리뷰 카드를 다 보여 준다. 우리는 리뷰·판매 숫자가 없으므로 **스펙 숫자(양면 2단계, 길이 등)와 소재 배지**로 자리를 채운다. 경쟁사 리뷰를 우리 리뷰처럼 쓰는 것은 금지 (원칙 2).
2. **"차별점 N가지" 요약 → POINT 번호 상세.** 한 화면 요약 뒤 POINT별로 펼친다. 스크롤 피로를 줄이는 바렌의 핵심 구조.
3. **양면 접사 비교.** 거친 면과 고운 면을 크게 확대해 나란히. "왜 두 면인가"를 한눈에.
4. **사용법 3단계 + 힘 조절 주의.** 바렌은 Q&A와 주의사항으로 "세게 밀면 상처" 불안을 먼저 꺼낸다. 리뷰 VOC 1순위와 맞고, 표시 규정 대응도 된다.
5. **공감 4컷 (더마풋).** 이불 속 거친 감촉, 샌들, 보이기 민망함, 스타킹 걸림. 품목 문제 자각 장치로 그대로 쓸 수 있는 구조다 (사진은 새로 만든다).

## 4. 버릴 것
- **수상 배지·누적 리뷰 수·노하우 연차:** 우리는 근거가 없다. 지어내면 허위 표시.
- **국내 제작·304 등급 주장:** 공급처가 중국 OEM이고 등급 근거가 없다.
- **비포·애프터 발 사진 (더마풋):** "갈라짐 개선" 오인 소지가 있고 실물 근거가 없다.
- **30일 무료체험·100% 환불:** 우리 운영 정책으로 정해지지 않았다. 등록 팀·사용자 결정 전에는 쓰지 않는다.
- **선착순 쿠폰 배너:** 가격·쿠폰은 등록 팀 소관이다.
- **"피부자극 無", "녹슬지 않는" 단정:** 근거 없는 단정 표현.
