## 3. 가져올 결제 장치 TOP 5
1. **"좋은 안대의 조건"을 먼저 정의하고 우리가 그 답이 되기 (컴포럽).** 고객의 판단 기준을 우리 강점(빛 틈, 귀 편함)으로 세팅한다.
2. **확대 말풍선으로 코 부분 보여 주기.** 품목 1순위 가치(코 옆 빛샘)를 사진 한 장으로 증명한다. 우리는 공급처 사진에 코 부분이 있으면 쓴다.
3. **"일반 ___ vs 우리 ___" 2컷 비교.** 귀걸이형(귀 아픔) vs 귀까지 감싸는 형태. 경쟁 브랜드를 지목하지 않는 일반형 비교로 쓴다.
4. **촉감 은유 + 손으로 누르는 컷.** 두툼한 패딩형은 "폭신함"을 보여 줄수록 이득이다.
5. **사용·세탁·보관 안내를 꼼꼼히.** 리뷰 VOC(새 제품 냄새, 먼지)를 미리 처리한다.

## 4. 버릴 것
- **시험성적서·암막률 99.9%·99.99%·27dB 같은 수치:** 우리에게 근거가 없다. 공급처가 수치를 내도 성적서 확인 전에는 쓰지 않는다.
- **멜라토닌·숙면·불면증 서사 (두 레퍼런스 모두):** 의학적 효능 암시다. "불면증 대표가 개발", "수면 호르몬", "꿀잠을 잘 수 있습니다", "빠르게 수면에 들 수 있다"는 쓰지 않는다 (원칙 1).
- **소음 dB 표·"무소음"·"소음 차단" (자요):** 근거가 없다. 귀덮개는 형태 표현까지만.
- **특허·정품·유사품 경고:** 우리에게 해당하지 않는다.
- **누적 판매·만족도 숫자:** 없다.
- **냉감 소구:** 자요의 영역이다. 우리 제품(두툼·귀덮개)과 계절(겨울)에 맞지 않는다.
