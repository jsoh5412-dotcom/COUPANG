# 카피용 팩트: 수면안대_6 (v2, 2026-11-03)

근거: `../analysis/source_spec.md`, 공급처 사진. 태그 `{F:번호}`로 인용한다.

## 쓸 수 있는 사실
| 번호 | 사실 | 재료 |
|---|---|---|
| F1 | 귀까지 덮는 넓은 통짜형 (착용 사진) | 귀 위까지 덮는 모습 |
| F2 | 귀에 거는 끈이 없다 (사진) | 귀 끈 0개 |
| F3 | 머리 뒤 벨크로로 고정, 길이 조절 (사진) | 뒤에서 한 번 |
| F4 | 전체 약 65cm, 폭 약 7~12cm (재는 위치에 따라 차이) | 65cm, 12cm |
| F5 | 코를 따라 내려오는 곡선 형태 (사진) | 코 곡선 |
| F6 | 두툼한 패딩 (사진, 두께 수치 없음) | 두툼, 폭신 |
| F7 | 겉감 나일론 90%·스판덱스 10%, 안감 폴리에스테르 100% (공급처 표기) | 정보표 |
| F8 | 색상 블랙·그레이·핑크 3종 | 3색 |
| F9 | 구성 1개 (공급처 표기 없음, 추정), 제조 중국 OEM | 정보표 |

## 쓸 수 없는 주장
| 주장 | 이유 |
|---|---|
| 빛 완벽 차단, 암막률 수치 | 시험 근거 없음 → "빛을 넓게 가려 주는" |
| 소음 차단, 방음, 무소음 | 근거 없음. 소리 관련 단어를 쓰지 않는다 |
| 통기성, 수분 흡수, 마이크로 에어 코튼 | 스펙표와 맞지 않음 |
| 숙면, 꿀잠, 불면 개선, 수면의 질 | 효능 암시 (원칙 1) |
| 눈을 누르지 않는 입체 구조 | 공급처 근거 없음 |
| 머리카락 안 붙는 벨크로 | 벨크로 종류 미확인 |
| 인체공학적 설계 | 근거 없음 |
| 세탁 방법 | 공급처 안내 없음 → 일반 안내만, 사실처럼 쓰지 않는다 |
| 누적 판매, 평점, 수상 | 우리 실적 없음 |
