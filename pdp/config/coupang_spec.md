# 쿠팡 상세페이지 규격

렌더·분할·QA가 따르는 기준값. 값을 바꾸면 `render.json`과 이 문서를 같이 고친다.

| 항목 | 값 | 근거 |
|---|---|---|
| 상세 이미지 가로폭 | **780px** | 판매자 가이드 다수의 공통값 (아래 출처) + 실제 쿠팡 판매 상세 22장이 모두 가로 779~780px (2026-10-27 수집 테스트). Wing 공식 문서는 로그인 필요라 미확인 |
| 분할 1장 세로 | 3,000px 이하 | 판매자 가이드 공통 |
| 형식 | JPG·PNG (GIF 불가) | 판매자 가이드 공통 |
| 대표이미지(썸네일) | 1000×1000px 정사각형 권장 | 쿠팡 Open API 문서: 최소 500×500, 최대 5000×5000, 3MB 이하 |

## 780px vs 860px 정리 (2026-10-27)
- 렌더러·템플릿(`render.mjs`, `components.css`)은 780px, `pdp/CLAUDE.md`의 글자 크기 예시는 860px였다.
- 쿠팡에 맞는 값은 780px로 정했다. 860px는 다른 오픈마켓·자사몰 기준이고, 규정 폭을 넘는 이미지는 잘리거나 축소되어 보일 수 있다.
- 780px 기준 최소 글자 크기 (`pdp/CLAUDE.md` 비율 적용): 본문 30px 이상, 소제목 42px 이상, 헤드라인 60px 이상.
  - 현재 `components.css`의 본문 `p` 26px는 이 기준에 못 미친다. 첫 상품 브리프에서 타깃이 정해지면 조정한다.

## 확인 필요
- Wing 판매자센터 도움말의 현행 공식 값. 사용자가 Wing에 로그인한 화면에서 한 번 확인하면 이 표의 "미확인"을 지운다.
